# Brand

The source of truth is the **lazytam** Figma file. It has four pages:

| Page | Contents |
|---|---|
| Brand | Guidelines: logo, color roles, typography, shape and motion, voice |
| Themes | joypad and paper cards: desktop preview, `colors.toml`, every swatch |
| Wallpapers | Wallpaper components, one row per design, one column per theme |
| README | `readme/glyphs`: outlined text used by the animated README headers |

Every color in the file is a variable in the `lazytam/theme` collection, with one mode per
theme (`joypad`, `paper`). Change a value there and every page, logo and wallpaper follows.
Hyprland's look (radius, gaps, border) is in the `lazytam/ui` collection.

## Logo

The mark is a Hyprland dwindle layout: three tiles, with the active window in red holding
the shell prompt. The wordmark is lowercase `lazytam` in JetBrains Mono Bold, with `tam` in
red.

- Always lowercase, even at the start of a sentence.
- Use the theme's colors; don't add gradients, glows, outlines or shadows.
- Keep a quarter of the mark's width clear around it. Smallest size: 16px (mark only below 96px).

## Color

| Role | joypad | paper | Used for |
|---|---|---|---|
| background | `#121212` | `#f2f0eb` | Windows, bar, lock screen |
| lighter_background | `#1e1e1e` | `#faf9f6` | Bar modules, cards, inactive borders |
| foreground | `#d0d0cb` | `#2b2a28` | Text |
| muted | `#5a5a58` | `#9b978e` | Secondary text, inactive workspaces |
| accent | `#a3a5a1` | `#5e5d58` | Focused border, current workspace |
| red | `#e0453b` | `#c8362d` | The one pop of color: logo, errors, keywords |

Red is used sparingly, like the buttons on a controller.

## Type

- **JetBrains Mono**: wordmark, headings, labels, code, anything you'd type.
- **Geist**: paragraphs and long text.

## Voice

lazytam talks like a good terminal tool: calm, short, specific.

| Say | Don't say |
|---|---|
| `:: theme: paper` | `🎉 Your beautiful new theme has been applied successfully!` |
| `warning: no ~/.ssh/authorized_keys yet: password SSH stays on` | `Error 0x3: SSH configuration could not be completed.` |
| `kitty: 'foot' is not installed` | `Oops! Something went wrong with your terminal.` |

No emoji, no exclamation marks, no blaming the user. Say what happened, then what to do.

## README headers

`docs/assets/header*.svg` are generated by `docs/assets/build.py` (`make readme`) from
`docs/assets/src/glyphs.svg`, which is the Figma frame `README / readme/glyphs` exported as
SVG. Text is outlined, so no fonts are embedded. The script's docstring explains how to
change the wording.
